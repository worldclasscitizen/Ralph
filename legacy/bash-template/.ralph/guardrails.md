# Ralph Guardrails

## 고정 안전 규칙

- 사용자 승인 없이 작업 목표나 범위를 확장하지 않습니다.
- 기존 사용자 변경을 덮어쓰거나 되돌리지 않습니다.
- 비밀값, 인증 파일, 개인 설정, 실행 로그를 커밋하지 않습니다.
- 테스트를 삭제·완화하거나 오류를 숨겨 통과시키지 않습니다.
- Worker는 `.ralph/**`, `.antigravity/**`, `.git/**` 제어면을 수정하지 않습니다.
- 검증되지 않은 사실이나 수치를 완료 증거로 사용하지 않습니다.
- 자동 push, 배포, 외부 서비스 변경은 수행하지 않습니다.
- 실패 원인은 최초 오류, 파생 오류, 환경 차단을 구분해 기록합니다.
