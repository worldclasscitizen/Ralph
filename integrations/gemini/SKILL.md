name: ralph
description: Start and monitor the platform-neutral Ralph CLI from Gemini CLI without duplicating its loop.
---

Resolve the absolute Git root. Run `ralph doctor`, then pass the request to `ralph draft --stdin --json` and run `ralph config explain --profile <contract.executionProfile>` for the exact routes. Present the contract and relevant route, then wait for explicit approval. After approval use `ralph run --contract-stdin --yes --events ndjson`. Ralph owns orchestration; Gemini CLI is only an input and display surface. Report observable evidence, never private reasoning.
