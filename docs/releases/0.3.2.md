# Ralph 0.3.2

[English](https://github.com/worldclasscitizen/Ralph/blob/v0.3.2/README.md) · [한국어](https://github.com/worldclasscitizen/Ralph/blob/v0.3.2/README.ko.md)

Ralph 0.3.2 is a release-tooling patch. The runtime, execution API, approval rules, catalog and evidence gates are unchanged from 0.3.1.

- The publish step no longer declares a publication missing on a single registry read. After `npm publish` it rechecks the npm registry up to seven times at ten-second intervals, so a slow read-after-write response completes the release instead of requiring a manual re-dispatch.
- A conflicting artifact still fails immediately: if the registry holds the same version with different bytes, the workflow stops rather than retrying, so a genuine mismatch is never masked.
- The 0.3.1 work ships unchanged: the 2026-09-27 model lineup, `ralph auth setup` onboarding, cross-platform credential storage and the strict login-state policy.

Install with npm install -g @worldclasscitizen/ralph@0.3.2. Node.js 22 or 24 and Git are required.

## Why this patch exists

The 0.3.1 publication passed the evidence gate, created the tag and filled the draft release, then stopped at `Published artifact not visible`: the registry answered `404` for a moment after a successful upload. Re-dispatching the same workflow for the same commit completed it, which confirmed the artifact was never the problem. That manual step is now unnecessary.

## Verification scope for 0.3.2

Provider and functional gates passed again on a real Codex session: four transport checks with `codex-cli 0.155.1` and `gpt-6-sol`, then a generated four-node graph completed in twelve model calls through starting-branch delivery, with two isolated scoped workers, independent reviews, integration, final validation and an external oracle. The recorded environment is Windows and Node.js 24.11.1; the ledger for this release consumed 16 calls and 475375 of the 1800000 active-millisecond ceiling, all through the recorded subscription connection.

Every other candidate, including `gemini-3.8-flash` and all API transports, remains protocol-tested only. Publication still requires the six-cell CI matrix on the exact merged commit. See [release readiness](../project/v0.3-readiness.md) and the [0.3.2 local verification record](../project/local-verification-0.3.2.json).

## 한국어 변경 사항

0.3.2는 릴리스 도구만 고치는 패치입니다. 런타임, 실행 API, 승인 규칙, 카탈로그, 증거 게이트는 0.3.1과 동일합니다.

- 게시 단계가 레지스트리 조회 한 번으로 실패하지 않습니다. `npm publish` 이후 최대 7회, 10초 간격으로 다시 확인하므로, 반영이 느릴 때 수동 재실행 없이 릴리스가 끝납니다.
- 바이트가 다른 같은 버전이 이미 있으면 재시도 없이 즉시 중단합니다. 실제 불일치를 재시도로 감추지 않습니다.
- 0.3.1의 작업(2026-09-27 모델 라인업, `ralph auth setup` 연동, 자격 증명 저장, 로그인 상태 정책)은 그대로 포함합니다.

0.3.1 게시는 증거 게이트와 태그, 초안 릴리스까지 통과한 뒤 "게시물이 보이지 않음"에서 멈췄습니다. 업로드 직후 레지스트리가 잠시 404를 돌려준 것이 원인이었고, 같은 워크플로를 다시 실행하자 그대로 완료되었습니다. 이제 그 수동 단계가 필요 없습니다.

0.3.2도 실제 Codex 세션으로 공급자·기능 게이트를 통과했습니다(`codex-cli 0.155.1`·`gpt-6-sol`, 4개 전송 검사, 12회 호출로 4노드 그래프를 시작 브랜치까지 반영). 원장 사용량은 16회 호출·475375ms(상한 1800000ms)이며, 나머지 후보 모델은 여전히 프로토콜 모의 검증 단계입니다.
