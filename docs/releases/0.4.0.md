# Ralph 0.4.0

- The redesigned dashboard keeps finished sessions searchable and reopens their last graph. It groups sessions across registered local projects when launched with `ralph dashboard --all`.
- Graph runs can repair failed nodes, accept a direction change during execution, and discard changes in an isolated workspace when cancelled.
- The dashboard shows provider limits, model availability, and simple Korean explanations of node activity.
- Catalog v7 adds GPT-6.2 Sol for the Codex subscription and the OpenAI API. Install Ralph 0.4.0 to trust the new catalog signing key.

Install with `npm install -g @worldclasscitizen/ralph@0.4.0`.
