# Ralph 0.3.1

[English](https://github.com/worldclasscitizen/Ralph/blob/v0.3.1/README.md) · [한국어](https://github.com/worldclasscitizen/Ralph/blob/v0.3.1/README.ko.md)

Ralph 0.3.1 is a catalog-only patch. The runtime, execution API, approval rules and evidence gates are unchanged from 0.3.0.

- The signed model catalog (`assets/catalog-v2.json`, catalog version 3 → 4, re-signed with the existing Ed25519 trust anchor) now carries the 2026-09-27 lineup of the five providers this project configures.
- Superseded ids are removed instead of kept as silent fallbacks: `gpt-5.6-*`, `gpt-5.4-mini`, `claude-sonnet-5`, `gemini-2.5-flash`, `gemini-3.7-flash`, `deepseek-v4-pro` and `glm-5` no longer appear in the routing pool.
- Every entry remains `qualityTier: "unrated"` with null measured scores. Selection stays deterministic catalog order; no quality, speed or cost ranking is invented.
- `scripts/bootstrap-catalog-v2.mjs` carries the same definitions, so a future bootstrap cannot resurrect a retired id.

Install with npm install -g @worldclasscitizen/ralph@0.3.1. Node.js 22 or 24 and Git are required.

## Verification scope for 0.3.1

No new live provider run was performed for this patch, and 0.3.1 does not claim one. The 0.3.0 certificate records `codex-cli 0.153.4` with `gpt-5.6-luna`; that model is no longer in the 0.3.1 catalog, so no entry in the 0.3.1 routing pool has live support evidence yet. Provider support therefore stays at `compatible` (protocol-level mock coverage) until a new conformance and end-to-end run records the model actually used. The 0.3.0 report, manifest, signatures and dates remain attached and unmodified; see [release readiness](../project/v0.3-readiness.md).

## 한국어 변경 사항

0.3.1은 카탈로그만 갱신하는 패치입니다. 런타임, 실행 API, 승인 규칙과 증거 게이트는 0.3.0과 동일합니다.

- 서명된 모델 카탈로그(카탈로그 버전 3 → 4, 기존 Ed25519 신뢰 앵커로 재서명)를 2026-09-27 기준 이 프로젝트가 설정하는 5개 공급자 라인업으로 교체했습니다.
- 대체된 모델 ID는 예비 경로로 남기지 않고 제거했습니다. `gpt-5.6-*`, `gpt-5.4-mini`, `claude-sonnet-5`, `gemini-2.5-flash`, `gemini-3.7-flash`, `deepseek-v4-pro`, `glm-5`는 더 이상 라우팅 후보가 아닙니다.
- 모든 항목은 `qualityTier: "unrated"`와 null 측정값을 유지합니다. 정렬은 결정적인 카탈로그 순서이며 품질·속도·비용 우위를 임의로 만들지 않습니다.

0.3.1에는 새로운 실공급자 검증이 없으며 주장하지도 않습니다. 0.3.0 증명서가 기록한 모델(`gpt-5.6-luna`, codex-cli 0.153.4)은 0.3.1 카탈로그에 없으므로, 현재 후보 풀에는 실제 지원 증거가 있는 모델이 없습니다. 새 적합성·종단 실행이 실제 사용 모델을 기록할 때까지 공급자 지원 등급은 `compatible`(프로토콜 모의 검증)에 머뭅니다. 0.3.0 보고서·매니페스트·서명·날짜는 수정하지 않고 그대로 보존합니다.
