**Functional gate: passed.** [The actual end-to-end report](evidence/live-functional.json) records run `run-54764ab5-a1f7-42b3-ab4c-b9b6bbfa8bed` at source `2396bce5decab06b2952d066bdc548c53c0dbbe9`: 12 model calls, 278914 wall-clock milliseconds, both isolated workers, final verification and starting-branch delivery completed. All frozen tests and the separate external oracle passed. Total campaign consumption is 58 calls and 1301435 active milliseconds; no extra paid API connection was used. The cumulative call-count cap is removed, while the shared 30-minute active-time ceiling remains. Earlier failures are retained in the [campaign history](release-campaign-2026-09-05.md); paired version comparisons are references.

Publication is a separate gate: the workflow requires successful CI for the exact main commit, verifies the same archive across six environments, installs from the npm registry, and only then publishes the GitHub Release. Attached release manifests and post-publication evidence identify the final source and package; this source document does not substitute for those checks. The [public artifact evidence](evidence/live-functional-artifacts.json) contains the successful node assessments, verifier output, diffs and resulting modules; disposable workspace paths are redacted with separate original and public-view hashes.

| Report | Required scope |
|---|---|
| CI | Windows, macOS, Linux × Node.js 22 and 24; exact archive integrity |
| Coverage | Global lines ≥57.77%, branches ≥73.70%; ten critical files ≥90% each |
| Operational | Five real process interruption boundaries, five repetitions, all three operating systems; automatic or explicitly inspected recovery to completion |
| Accessibility | Four browser cases including 32 nodes, eight revisions and 100,000 log lines |

| Catalog | Separate v2 signature, source audit, unchanged legacy catalog and signature |
| Installation | Exact/default registry install, initialized Git state, bundled UI and mock graph completion |

VerificationReportV2 and ReleaseManifestV2 bind required evidence to the source and tested archive. V1 reports remain readable. The fixed stable-functional-v1 profile requires all functional and reliability checks; historical comparisons and original reused reports appear as hashed references. Missing, stale, failed or mismatched required evidence blocks publication. End-to-end evidence requires matching runtime/dependency/harness digests and expires after 30 days.

EvidenceReuseV2 preserves the original provider report, date, environment and file hash. Verification parses the Codex adapter and conformance fixture helper imports, recursively including their relative value and type dependencies. Those source files, the exact conformance script and lockfile must match their original commit. Release accounting is now tested separately for count preservation, active time, interruption and ownership; its change still invalidates the end-to-end harness identity. V1 certificates remain readable with their original additional accounting-file check. Planner prompts and comparison fixtures belong to the separate end-to-end protocol. Release serialization and gate logic are tested without model calls. An unavailable source commit, altered report, changed execution dependency or changed CLI/model/environment blocks reuse.

Local reports live in the ignored .release/evidence directory; CI uploads evidence artifacts. Public live reports are committed under docs/project/evidence only after execution. The final manifest and reports are attached to the GitHub Release. Historical beta smoke records in [provider evidence](../providers/index.md) do not establish current stable support.

## Reproduce without model costs

```bash
npm ci
npm run build
npm test
npm run test:coverage
npm run check:core
npm run test:operational
npm run test:e2e
npm run docs:check
npm run docs:build
npm run smoke
npm run test:live:release -- --dry-run
```

The last command exercises generated planning and full delivery with mock responses. The expected normal path is eight calls: three planning, four worker/review, one final review. This is an estimate, not a call limit. The live run receives no injected contract or graph. The test approves only the exact generated plan after checking scope and verifiers. There is no cumulative call-count cap. Each campaign retains its consumed active time under the 30-minute ceiling; reruns read the durable ledger. Failures and cancellations are recorded; restarting does not reset consumption. Actual testing requires --live and an authenticated recorded Codex connection, with no paid API connection. Historical comparison tooling remains available through test:live:comparison. See [release procedure](../RELEASING.md).

## 0.3.1 release evidence

## Explicit limits

One local project supervisor; no remote workers, shared service or consumer auto-push/deployment. Worktrees are not security sandboxes. Intermediate dependency conflicts retain work and pause. Final merge/verification failures have bounded repair workers. [Interrupted execution](../architecture/recovery.md) requires inspection when an external outcome cannot be established.

Fresh provider sessions carry evidence between iterations. No private internal reasoning is collected. Unknown pricing/usage cannot provide a strict monetary cap. Verifiers with shared external resources are serialized. Provider support is limited to the exact recorded model, CLI and environment; compatible endpoints are not advertised as live verified.
